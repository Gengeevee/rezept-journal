# 🍳 Mein Rezept Journal

Eine moderne Web-App (PWA) im iOS-Design zum Verwalten, Erstellen und Bearbeiten deiner Lieblingsrezepte.

## 📱 Features

- **iOS-Design:** Dunkles, elegantes Design optimiert für Smartphones.
- **Rezept-Verwaltung:** Neue Rezepte hinzufügen, eigene Cover-Bilder hochladen, Zutaten & Anleitungen bearbeiten oder löschen.
- **Kategorien:** Schneller Zugriff auf Frühstück, Mittagessen und Dessert.
- **Progressive Web App (PWA):** Lässt sich direkt als App auf dem Home-Bildschirm von iOS und Android installieren.
- **Offline-Funktionalität:** Dank Service Worker auch im Funkloch oder beim Einkaufen ohne Internetverbindung nutzbar.
- **Lokaler Speicher:** Alle Rezepte werden privat und sicher im `localStorage` deines Geräts gespeichert.

## 🛠️ Technologien

- HTML5
- CSS3 (Custom Variables, CSS Grid, Flexbox)
- JavaScript (Vanilla JS)
- Service Worker & Web App Manifest (`sw.js`, `manifest.json`)

## 🚀 Installation auf dem Smartphone

1. Öffne den GitHub-Pages Link im Browser auf deinem Handy.
2. **iOS (Safari):** Tippe auf das Teilen-Symbol (Viereck mit Pfeil) → *Zum Home-Bildschirm*.
3. **Android (Chrome):** Tippe auf die drei Punkte → *Zum Startbildschirm hinzufügen* / *App installieren*.

Hope it works...
